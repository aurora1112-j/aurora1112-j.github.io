<LanguageBlock lang="zh">

工作记忆服务于正在进行的任务；经历记忆保留做过什么、为什么这么做；长期知识保存相对稳定的事实与偏好。

三者不能只是按时间堆叠。它们需要不同的写入门槛、过期机制与用户控制。否则短期噪声会逐渐伪装成长期偏好。

与 [[让个人知识花园与 AI 一起生长]] 的关系：个人知识花园更接近可编辑的长期知识层，但必须保留来源与修订历史。
</LanguageBlock>

<LanguageBlock lang="en">
Working memory serves the task in progress. Episodic memory preserves what happened and why. Long-term knowledge holds relatively stable facts and preferences.

The three layers need different writing thresholds, expiry rules, and user controls. Otherwise temporary noise gradually masquerades as a durable preference.

In relation to [growing a personal knowledge garden with AI](/personal-knowledge-garden): the garden resembles an editable long-term knowledge layer, but it must retain provenance and revision history.
</LanguageBlock>
