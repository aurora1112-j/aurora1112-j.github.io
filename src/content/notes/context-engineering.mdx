Prompt 是一次请求的表面，上下文则是 Agent 做判断时能看到的世界。

可以暂时把上下文分成五层：任务目标、当前状态、可用工具、相关记忆和输出约束。真正的设计问题不是“塞入越多信息越好”，而是让每一层都能被选择、更新和追溯。

<LanguageBlock lang="en">
A prompt is the surface of one request. Context is the world an agent can see while making decisions.

For now, I divide context into five layers: goals, current state, available tools, relevant memory, and output constraints. The design problem is not how much information we can stuff in, but how each layer can be selected, updated, and traced.
